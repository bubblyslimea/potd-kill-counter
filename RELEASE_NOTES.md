# a little counter for the climb

the first alpha of Riri's PotD Counter is here

it watches the kills your client receives, remembers Flight across floors, and gives you a rough idea of how much fighting might be left
the game decides when the passage opens, the counter follows along

add the [shared Riri repository](https://give-riri-a-cookie.pages.dev/plugins/repo.json), enable plugin testing builds, then look for **Riri's PotD Counter** in `/xlplugins`
if you already use the Pages `/notation/repo.json` address, keep that row, both addresses serve the same catalog

open `/potdcount` for settings or `/potdcount preview` to try the simulation outside PotD

this build passed its offline behavior checks and compilation, live game testing is still pending
please try a low-floor run before bringing it into an important climb

[installation and testing notes](https://github.com/bubblyslimea/potd-kill-counter/blob/main/TECHNICAL_DETAILS.md)
